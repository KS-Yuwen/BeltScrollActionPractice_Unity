# Neon Street — 3D Belt Brawler Prototype

Unity 6000.6.4f1 用の試作です。Unity Hub でこのフォルダをプロジェクトとして追加します。
`Assets/Scenes/NeonStreet.unity` を開き、Play を押してください。

- WASD / 矢印: 左右・奥行き移動
- J / Space: 通常攻撃（続けて押すと3段コンボ）
- 左 Shift: 回避ダッシュ（方向入力がなければ向いている方向へ移動）
- K 長押し: 盾ガード（正面の攻撃だけ防ぎます）
- 防御成功後0.45秒以内に攻撃: カウンター（36ダメージ）。ガードを押したままでも使えます。
- 回避ダッシュ中に攻撃（または回避＋攻撃の同時押し）: ダッシュ攻撃。
- R: リスタート
- L / パッド Y（Xbox）・△（PlayStation）：自己回復魔法。HP を30回復、1プレイ3回。
- I / パッド B（Xbox）・○（PlayStation）：プロテクション。8秒間、被ダメージを半減（奇数は切り上げ）、1プレイ2回。

プロテクションは回復とは別の使用回数を持ち、効果中は金色になります。効果時間と残り回数を画面に表示します。
発動後0.6秒の隙があり、効果中の再使用では回数を消費しません。効果時間は硬直中も経過し、ウェーブ間では補充されません。

回復は満タン・被ダメージ硬直・攻撃・回避中には発動せず、回数も消費しません。
使用後0.6秒は移動・攻撃・回避・ガードができず、ダメージも受けます。
ウェーブが進んでも使用回数は補充されず、リスタートで3回に戻ります。残り回数は画面に表示します。
`ClericFighter.cs` は `Fighter` を継承し、職業固有の回復魔法を担当します。

ゲームパッド操作（Input System が Gamepad として認識する機種）：
- 左スティック／十字キー：移動。スティックは倒した量に応じて速度が変わります。
- X（Xbox）／□（PlayStation）：通常攻撃。
- A（Xbox）／×（PlayStation）：ジャンプ。RB／R1：回避ダッシュ。
- LB／L1 または LT／L2 長押し：盾ガード。ガード中は移動・通常攻撃を止めます。
- Start／Options：リスタート。

パッドは実行中の接続・取り外しに対応し、キーボードも引き続き使えます。
Uキー／パッドA・×でジャンプし、上＋ジャンプで大ジャンプ、回避ダッシュ中のジャンプでダッシュジャンプになります。
下＋ジャンプを保持するとしゃがみ、しゃがみ中に攻撃すると12ダメージのしゃがみ攻撃になります。しゃがみ中は移動・ガードを止めます。
ジャンプを0.25秒以内に2回押すと、向きを維持して後方へバックステップします（0.14秒の回避無敵・再使用待ち0.6秒）。
大ジャンプ・ダッシュジャンプ・空中攻撃中からはバックステップに切り替わりません。しゃがみ自体には無敵や攻撃を避ける効果はありません。
向いている方向を0.25秒以内に2回入力し、2回目を保持すると継続ダッシュします（速度8、通常歩行5）。離す・逆方向に入れる・ガード・被ダメージで終了します。
継続ダッシュには無敵がなく、前方の敵への接触で8ダメージの体当たりを出します。同じ敵には1回のダッシュにつき1回だけ命中します。
走りながら攻撃でダッシュ攻撃、ジャンプでダッシュジャンプへ移れます。Shift／RBの短い回避ダッシュは引き続き使えます。
下→斜め前下を0.9秒以内に入力し、その後0.6秒以内にジャンプを押すとスライディングします。右向きではS→S+D＋U、左向きではS→S+A＋Uです。

操作・移動・攻撃・重装型・魔法・ポーションの主な調整値は `BrawlerBalance.cs` の名前付き定数に集約しています。
方向の種類や未設定の時刻は `BrawlerDefines.cs` に定義し、調整値とは分けています。
現時点では定数による設定です。将来はCSVを起動時に読み取り、型・範囲・必須項目を検証した設定オブジェクトを、この設定窓口へ渡す構成にします。
ジャンプを保持すると最大0.4秒、早く離すと最短0.12秒滑ります。前方の敵に12ダメージ（同じ敵には1回）、無敵はなく被ダメージで中断します。
下＋ジャンプだけなら従来のしゃがみになります。方向入力の履歴は `DirectionCommandBuffer.cs` が担当します。
ジャンプ中の攻撃は20ダメージ、下＋攻撃は32ダメージの下突きです。空中でも左右・奥行きに移動できます。
高さ0.6を超えると地上攻撃を避けられます。離陸直後・着地間際は攻撃を受け、空中ではガード・回復・プロテクションを使えません。
資料の操作との対応・今後の実装順は `CONTROLS_ROADMAP.md` を参照してください。
汎用 HID ジョイスティックなど Gamepad として認識されない機種には、別途レイアウト設定が必要です。
入力は `BrawlerInput.cs` に集約しています。Input System 1.20.0 を導入し、Active Input Handling は Input System に設定しています。
両方の入力が効かない場合は、Play を停止して `Tools > Neon Street > Apply Input Settings and Restart` を実行してください。
このメニューは Unity 内で入力設定を適用し、編集中のシーンを保存する機会を設けてからエディターを再起動します。
再起動後は Game ビューをクリックして入力フォーカスを与えてください。

敵を倒すと次のウェーブが登場します。HP がゼロになると敗北します。
第1ウェーブは右側、第2ウェーブ以降は左右から敵が登場します（ステージ端では空間のある側を使います）。
出現前に1.5秒の予告と出現位置を表示し、画面外は端の矢印で知らせます。出現位置は予告開始時に固定されます。
敵を3体倒すごとに緑の回復ポーションが落ちます。0.7以内に近づくと自動で拾い、HPが20回復します。
満タン時は拾わず、床に残ります。ポーションは20秒で消え、回復魔法の使用回数には影響しません。
`HealingPotion.cs` は拾得距離・回復・二重取得防止を担当し、撃破時の生成は `BeltBrawler.cs` が担当します。
敵が黄色になり「!」が出たら攻撃の予告です。奥行き移動や無敵付きの回避ダッシュで避けられます。
予告中に攻撃を当てると敵の攻撃を中断できます。3段目は強い吹き飛ばしになります。
敵への命中で通常攻撃は0.04秒、3段目・ダッシュ攻撃・カウンターは0.08秒のヒットストップが入ります。
命中位置に黄色の打撃エフェクトを表示します。複数同時命中でも停止時間を足さず、リスタート時は停止を解除します。
通常の命中・強い命中・ガード成功・回復・プロテクション・ポーション取得には、それぞれ異なる仮効果音があります。
`BrawlerAudio.cs` が起動時に音を生成して共有します。外部音声素材は不要で、ヒットストップ中も再生します。
音量は AudioSource の volume（初期値0.35）で調整できます。範囲攻撃の同種音は短時間の重複再生を抑えます。
通常攻撃には0.2秒の入力先行受付があり、攻撃終了の少し前に押しても次につながります。
2秒以内に続けて命中させると連続ヒットが増え、獲得スコアが上がります。被ダメージで連続ヒットはリセットされます。
全滅後は次のウェーブ開始時にHPが15回復します。敵の頭上に残りHPを表示します。
赤い敵は近接型、紫の敵は遠距離型です。遠距離型は距離を取り、0.8秒の予告後に直進する弾（8ダメージ）を撃ちます。
第2ウェーブから橙色の重装型が1体混ざります。HPは100＋ウェーブ数×8、移動速度1.3（通常2.2）、予告0.95秒、一撃24ダメージです。
重装型も正面ガード・予告中の攻撃による中断・転倒と追撃が有効です。`HeavyFighter.cs` が `Fighter` を継承して能力を上書きします。
弾は追尾しません。奥行き移動や回避で避けるか、敵の方を向いてガードしてください。近づいて予告を中断することもできます。
キャラクターは図形を組み合わせた仮モデルです。アニメーション、実モデル、効果音は今後の作業です。

シーンを再生成する場合は Unity のバッチモードで `-executeMethod CreateDemo.BuildScene` を使用します。

コードを読む順序は `BeltBrawler.cs`（ゲーム全体）→ `Fighter.cs`（キャラクターの更新・戦闘）がおすすめです。
`Combatant.cs` は HP の初期化・回復・減少を担当する抽象基底クラスで、`Fighter` が継承しています。
`RangedFighter.cs` は `Fighter` を継承し、間合いの判断と攻撃方法を上書きします。弾の移動・命中は `EnemyProjectile.cs` が担当します。
3段目は敵を転倒させ、約0.7秒後に起き上がります。ガード成立時は緑に点滅し、背後からの攻撃は防げません。
向いている側のダウン中の敵（左右1.8未満・奥行き0.8未満）の近くで通常の攻撃ボタンを押すと、24ダメージの専用追撃を出します。
対象は一番近い1体、1回のダウンにつき1回だけです。起き上がりを延長せず、命中前に距離が離れたり起き上がったりすると空振りします。
追撃中も被ダメージで中断されます。カウンター・ダッシュ攻撃はそちらの操作が優先されます。
ダッシュ攻撃は32ダメージで、範囲内の敵をまとめて吹き飛ばします。回避の無敵は発動時に終了し、被ダメージで中断されます。
通常攻撃のリーチ（プレイヤー2.475）は共通です。踏み込みの後には0.6秒の攻撃待ち時間があります。
採用する命名・書式は `CODING_STYLE.md` に記載し、対応 IDE 向けに `.editorconfig` を用意しています。
戦闘ルールの自動検証は `-batchmode -nographics -executeMethod CombatValidation.Run` で実行できます。
