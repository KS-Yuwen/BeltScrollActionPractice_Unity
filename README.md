# Neon Street — 3D Belt Brawler Prototype

Unity 6000.6.4f1 用の試作です。Unity Hub でこのフォルダをプロジェクトとして追加します。
`Assets/Scenes/NeonStreet.unity` を開き、Play を押してください。

最終（第5）ウェーブはボス「WARDEN」1体との戦闘です。紫の鎧と大きな鈍器で区別し、画面右上にHPと行動状態を表示します。長い一撃（リーチ2.4・予告0.9秒）と、幅広い攻撃（リーチ1.8・奥行き±1.4・予告0.7秒）を交互に使用します。長い一撃の予兆は橙色、幅広い攻撃は紫色で表示し、発動が近づくと色が濃くなります。予告中は向きが固定されるので、床の範囲を見て回避・正面ガードで対処してください。

第4ウェーブを突破するとボス前の準備区間に入り、HPを40回復します。ポーション・ハンマー・回復／防御／攻撃強化スクロールを一つずつ支給します。移動・取得・所持欄の選択・魔法使用は引き続き可能で、通常の6スロット・上限9の規則に従います。準備中の支給品は時間切れになりません。

準備ができたらEnter／パッドStart・Optionsでボス戦を開始してください。攻撃中・空中・魔法使用後の隙では開始できず、落ち着いてから押し直します。開始後は出現予告を経てボスが現れ、残った支給品の通常の寿命を再開します。準備中のStartは戦闘開始に使用し、Rキーは引き続きリスタートできます。回復量・支給品の間隔は `BrawlerBalance` のBossPreparation定数で調整できます。

攻撃後は命中・ガード・空振りに関係なく1.4秒停止し、OPENINGと表示します。足元の緑色の小さな枠と、右上の残り時間バーが反撃の隙を示します。この間に反撃できます。予告中の被弾による中断、転倒・追撃、ハンマーの気絶・最大2ヒットは既存の戦闘処理を共用します。ボス撃破時は最後の一撃のヒットストップ後に0.6秒間、速度を25％に落とします。「BOSS DEFEATED」を1.2秒表示し、表示と消滅演出の両方が終わってからステージクリアへ進みます。低速再生・表示の秒数は実時間で計測し、リスタートやPlay終了時にも速度を復元します。HP・威力・範囲・予告・隙は `BrawlerBalance` のBoss定数で調整できます。

ボスのHPが半分以下になると一度だけ後半へ移行し、右上に2秒間「PHASE 2 — SPEED UP」を表示します。名前にP2が付き、HPバーが赤橙色になります。移動速度は2.0から2.4へ上がり、1.4秒の反撃の隙が終わってから次の予兆までの追加待機が0.3秒から0.1秒になります。攻撃の種類・威力・範囲・予兆時間・反撃の隙は維持します。移行時に進行中の攻撃や隙をリセットしません。後半の調整値は `BrawlerBalance` のBossSecondPhase定数です。

敵の予兆開始には上昇する合図音、予兆終了後の振り始めには風切り音、近接攻撃の範囲外へ避けた場合には短い空振り音を再生します。ボスは低い音域で通常敵と区別します。遠距離敵も予兆・発射動作で音を出し、避けられた弾は寿命終了時に空振り音を出します。ガード時や無敵中の接触では空振り音を追加しません。音域・持続時間は `BrawlerAudio` の定数で調整できます。

通常コンボは実際にダメージを与えた後の攻撃入力で次段へ進みます。命中前の連打は予約せず、空振り・無敵による命中拒否・向きの変更では初段から開始します。命中後の入力は0.2秒先行受付でき、命中から0.85秒以内に次の通常攻撃を開始すると継続します。最終段からは次段を予約しません。

命中判定後のモーション・後隙中に、通常攻撃からニュートラル→前→攻撃で大斬り、通常攻撃や地上の特殊技からコマンド入力でダッシュ必殺技・対空必殺技へキャンセルできます。必殺技同士はダッシュ必殺技→対空必殺技のみです。空振り後も上位技へのキャンセルは可能ですが、同じ技や下位技へのキャンセルはできません。方向入力の受付時間は従来どおりです。

方向とボタンは別の入力更新で入れてください。方向入力後、該当方向を保持してからボタンを押します。受付時間は方向0.9秒・ボタン0.6秒を維持しています。大斬りのボタン受付も0.6秒です。ガードは攻撃保持→後ろ方向で成立し、今回の方向先行条件の対象外です。

- WASD / 矢印: 左右・奥行き移動
- J / Space: 通常攻撃（命中後に押すと次段へ進む3段コンボ。空振りは初段のみ）
- 左 Shift: 回避ダッシュ（方向入力がなければ向いている方向へ移動）
- 後ろ方向＋攻撃長押し: 盾ガード。攻撃を離すまで構えを維持し、向きを固定します。ガード中に前方向を入れると、敵の攻撃を防ぐ前でも対空攻撃へ移ります。専用ガードボタンでも同じ操作が可能です。解除後は0.2秒間無敵になります（調整用定数で変更可能）。
- ガード中に前方向: 防御成功を待たず対空攻撃へ移行（クリティカル補正後54ダメージ）。
- K 長押し: 盾ガード（正面の攻撃だけ防ぎます）
- 防御成功後0.45秒以内に攻撃: カウンター（36ダメージ）。ガードを押したままでも使えます。
- 回避ダッシュ中に攻撃（または回避＋攻撃の同時押し）: ダッシュ攻撃。
- R: リスタート
- L / パッド Y（Xbox）・△（PlayStation）：自己回復魔法。HP を30回復、初期3回・上限9回。
- I / パッド B（Xbox）・○（PlayStation）：プロテクション。8秒間、被ダメージを半減（奇数は切り上げ）、初期2回・上限9回。

プロテクションは回復とは別の使用回数を持ち、効果中は金色になります。効果時間と残り回数を画面に表示します。
プロテクションは詠唱0.4秒→発動演出0.25秒→後隙0.6秒です。回数は詠唱開始時に消費し、防御効果と8秒の持続時間は詠唱完了時に開始します。詠唱中の被弾で中断すると回数は戻らず、効果も付きません。発動演出中は金色になり、敵・ボス・飛行中の弾を停止します。効果中の再使用では消費も時間延長も行いません。効果時間は発動演出・後隙・被弾硬直中も経過し、ウェーブ間では補充されません。

回復は満タン・被ダメージ硬直・攻撃・回避中には発動せず、回数も消費しません。
回復魔法は詠唱0.4秒→発動演出0.25秒→後隙0.6秒の流れです。詠唱開始時に1回消費し、詠唱完了時にHPを回復します。詠唱中の被弾で中断した場合、回数は戻らず回復も発生しません。腕の構え・黄色い詠唱表示から緑色の発動表示へ移り、発動演出中だけ敵・ボス・飛行中の弾を停止します。各段階で移動・攻撃・回避・ガードはできず、無敵は付けません。
ウェーブが進んでも使用回数は補充されず、リスタートで3回に戻ります。残り回数は画面に表示します。
`SpellFighter` は `ItemFighter` を継承し、魔法の予約・消費・詠唱・発動演出・後隙・被弾中断を共通管理します。`ClericFighter` と `AttackSpellFighter` が継承し、職業固有の効果は `ApplySpell` に定義します。回復魔法の時間は `HealingCastSeconds`・`HealingEffectSeconds`・`SpellRecoverySeconds` で調整します。

所持欄はアイテム・魔法共通の6スロットです。各種類は個別に最大9まで持てます。初期所持は回復3回・プロテクション2回・攻撃強化2回で、残り3枠はNOTHINGです。使い切った枠はNOTHINGに戻り、他の枠は詰め直しません。取得時は同種の枠へ加算し、新しい種類は最初の空き枠へ入ります。満枠・上限9では床に残ります。

敵を通算4体倒すごとに、対応する魔法だけを1回補充するスクロールが落ちます。緑の帯は回復、金色はプロテクション、オレンジ色は攻撃強化で、この順に出現します。近づくと自動で取得し、現在HPや選択中の枠に関係なく補充します。未対応の職業では取得できず、床に残った物は20秒で消えます。死亡・ゲーム終了後は取得できません。

所持数は `ActionInventory` に集約し、別の魔法回数状態を持ちません。スロット数・所持上限・初期回数・スクロール補充量・ドロップ間隔は `BrawlerBalance` の定数で調整できます。

攻撃強化（ATTACK BOOST）は、Q／View・Shareで選択し、E／RT・R2で使用します。選択は空き枠を含む6枠を循環します。使い切っても選択位置は変わらず、NOTHINGの使用は何も消費しません。13秒間、武器による近接攻撃と追撃のダメージを1.5倍にし、端数を切り上げます。投擲・ターニングアンデッド・体当たり・スライディングには適用しません。

攻撃強化とプロテクションの使用回数は独立しています（それぞれ初期2回・上限9回）。併用可能ですが、効果中の同じ魔法の再使用では回数を消費せず、効果時間も延長しません。攻撃強化も詠唱0.4秒→発動演出0.25秒→後隙0.6秒です。詠唱開始時に回数を消費し、詠唱完了時に威力倍率と13秒の持続時間を開始します。発動演出は橙色で表示し、敵・ボス・飛行中の弾を停止します。詠唱中に被弾すると中断し、回数は戻らず効果も付きません。無敵は付けません。残り時間と終了予告を選択欄に表示します。詠唱・演出時間は `ProtectionCastSeconds`・`ProtectionEffectSeconds`・`AttackBoostCastSeconds`・`AttackBoostEffectSeconds`、後隙は `SpellRecoverySeconds` で調整できます。倍率・持続時間も `BrawlerBalance` の定数で管理します。

ゲームパッド操作（Input System が Gamepad として認識する機種）：
- 左スティック／十字キー：移動。スティックは倒した量に応じて速度が変わります。
- X（Xbox）／□（PlayStation）：通常攻撃。
- A（Xbox）／×（PlayStation）：ジャンプ。RB／R1：回避ダッシュ。
- LB／L1 または LT／L2 長押し：盾ガード。ガード中は移動・通常攻撃を止めます。
- Start／Options：リスタート。

パッドは実行中の接続・取り外しに対応し、キーボードも引き続き使えます。
Uキー／パッドA・×でジャンプし、純粋な上を先に入れてからジャンプで大ジャンプ、回避ダッシュ中のジャンプでダッシュジャンプになります。
純粋な下を先に入れ、その後ジャンプを保持するとしゃがみ、しゃがみ中に攻撃すると12ダメージのしゃがみ攻撃になります。しゃがみ中は移動・ガードを止めます。
攻撃・選択・使用ボタンの後、0.25秒以内にジャンプを押すか、ジャンプを2回押すと、向きを維持して後方へバックステップします（0.14秒の回避無敵・再使用待ち0.6秒）。
地上の攻撃は中断できます。魔法・アイテム使用後の硬直、大ジャンプ・ダッシュジャンプ・空中攻撃中からはバックステップに切り替わりません。しゃがみ自体には無敵や攻撃を避ける効果はありません。
ニュートラル→純粋な前→ニュートラル→純粋な前を0.25秒以内に入力し、2回目を保持すると継続ダッシュします（速度8、通常歩行5）。離す・逆方向に入れる・ガード・被ダメージで終了します。
継続ダッシュには無敵がなく、前方の敵への接触で8ダメージの体当たりを出します。同じ敵には1回のダッシュにつき1回だけ命中します。
走りながら攻撃でダッシュ攻撃、ジャンプでダッシュジャンプへ移れます。Shift／RBの短い回避ダッシュは引き続き使えます。
下→斜め前下を0.9秒以内に入力し、その後0.6秒以内にジャンプを押すとスライディングします。右向きではS→S+D→U、左向きではS→S+A→Uです（最後の斜め方向は保持）。開始時のニュートラルは不要ですが、斜め入力とジャンプの同時入力は受理しません。

操作・移動・攻撃・重装型・魔法・ポーションの主な調整値は `BrawlerBalance.cs` の名前付き定数に集約しています。
方向の種類や未設定の時刻は `BrawlerDefines.cs` に定義し、調整値とは分けています。
スライディングは `Assets/Resources/Balance/slide_balance.csv` をPlay開始時に読み込みます。編集・保存してUnityのインポート完了後、Playを開始し直すと反映されます。
ヘッダーは `key,value`、各行は設定名と数値の2列です。UTF-8、小数点は `.`、引用符や桁区切りを使わず、コメント行は `#` で始めます。
一部の設定だけ指定しても構いません。省略項目は既定値を使います。ファイル欠落・不正値・未知の設定名・重複がある場合は全項目を既定値に戻し、Consoleに警告します。
受付時間・行動時間は0.01～3秒、速度は0.1～30、ダメージは整数1～1000、方向しきい値は0.05～0.9です。最短時間は最長時間以下にしてください。
CSVはビルドに同梱されます。現在はPlay開始時の読み込みで、実行中の再読み込みやビルド後の外部CSV編集には未対応です。
ジャンプを保持すると最大0.4秒、早く離すと最短0.12秒滑ります。前方の敵に12ダメージ（同じ敵には1回）、無敵はなく被ダメージで中断します。
純粋な下を入れてからジャンプを押すとしゃがみになります。方向入力の履歴は `DirectionCommandBuffer.cs` が担当します。
ニュートラル→純粋な下→斜め前下の後に攻撃を押すと、ダッシュ必殺技になります。既定の基礎威力は40（クリティカル補正後60）、速度10で0.25秒踏み込み、0.4秒の攻撃・0.75秒の再使用待ちです。
左右の向きに対応し、無敵はなく被ダメージで中断します。攻撃＋ジャンプの同時入力はスライディングを優先します。
CSVの `DashSpecialDamage` / `DashSpecialSpeed` / `DashSpecialMovementSeconds` / `DashSpecialAttackSeconds` / `DashSpecialCooldownSeconds` / `DashSpecialHitDelaySeconds` で調整できます。
受付時間と方向しきい値はスライディングと共通です。必殺技の移動・命中時刻は攻撃時間内、再使用待ちは攻撃時間以上にしてください。
ニュートラル→純粋な下→ニュートラル→純粋な上→攻撃で対空必殺技を出します（S→離す→W→J、またはパッド下→離す→上→X・□）。最後の上方向は保持し、上と攻撃の同時入力は受理しません。向きを維持して鈍器を振り上げ、基礎威力36（クリティカル補正後54）・リーチ1.8の単発攻撃を出します。
既定は方向受付0.9秒・ボタン受付0.6秒・攻撃0.45秒・再使用待ち0.7秒です。無敵はなく、被ダメージで中断します。地上の敵にも命中します。
同じCSVの `UppercutDirectionWindowSeconds` / `UppercutButtonWindowSeconds` / `UppercutDamage` / `UppercutAttackSeconds` / `UppercutCooldownSeconds` / `UppercutHitDelaySeconds` / `UppercutReach` で調整できます。
地上でニュートラル→純粋な前方向→攻撃を押すと大斬りになります。前方向は保持し、前と攻撃の同時入力や斜め方向では大斬りになりません。既定の基礎威力は34（クリティカル補正後51）・リーチ2.8・攻撃0.5秒・再使用待ち0.7秒です。方向コマンド技・走行中の攻撃・追撃を優先します。
通常攻撃が実際に命中するまで攻撃ボタンを保持すると、その場で突き飛ばしへ移ります（追加10ダメージ・押し戻し速度12）。空振り・大斬りでは発動しません。
1回の長押しで突き飛ばしは1回だけです。空中・しゃがみ・ガード・回避・魔法や被ダメージでは長押しを解除し、無敵は付けません。
同じCSVの `HeavyStrike` / `Push` で始まる設定で威力・時間・リーチを調整できます。`PushHoldSeconds` は旧設定との互換用で現在の入力判定には使用しません。`PushKnockbackSpeed` が押し戻し速度です。
ジャンプ中の攻撃は20ダメージ、下＋攻撃は32ダメージの下突きです。空中でも左右・奥行きに移動できます。

## 魔法・アイテムの選択と共通使用

Q / パッドのView・Shareで、回復→プロテクション→ポーション→スローイングハンマーの順に選択します。E / RT・R2で選択中の魔法・アイテムを使用します。画面のSELECTEDに選択名と残り回数を表示し、POTIONSに所持数と上限を表示します。初期選択は回復です。

選択だけでは回数を消費せず、攻撃や魔法の硬直中も選択できます。選択と使用の同時押しでは切り替え後の項目を使います。長押しでは連続切り替え・連続発動しません。満タン時の回復、効果中のプロテクション、使用回数ゼロ、空中や行動中の発動は回数を消費せず失敗します。

L / Y・△の回復、I / B・○のプロテクションは直接発動として残します。直接発動と共通使用の同時入力は、回復→プロテクション→選択魔法の順に判定し、成立した最初の一つだけを発動します。

ポーションは使用時にHPを20回復します。使用後0.6秒の隙があり、無敵は付きません。HP満タン・所持数ゼロ・空中や行動中には消費しません。魔法の残り回数とは独立しています。

## ターニングアンデッド

J / Space＋U、パッドのX・□＋A・×で発動します。片方を保持してもう片方を押す操作も受け付けます。地上で行動可能なときに、向きに関係なくXZ平面の半径4以内のアンデッドへ40ダメージを与えます。通常敵には効きません。各ウェーブの2体目に淡い骨色のアンデッド敵を配置します。

HP・魔法回数・ポーションを消費せず、再使用まで4秒、発動後の隙は0.6秒です。無敵は付かず、空中・被ダメージ硬直・他の行動中には使えません。対象がいなくても発動します。下入力中はしゃがみ・スライディング系の既存操作を優先します。画面に再使用までの時間を表示します。数値はBrawlerBalanceの名前付き定数で調整できます。試作用の設定です。

## スローイングハンマー

敵を2体倒すごとに銀色のハンマーが1個落ちます。床上の距離0.7以内で拾って保存し、最大9個まで所持できます。床では20秒で消え、所持後は期限なくウェーブ間も保持します。リスタートで所持数は初期化されます。

Q / View・Shareでスローイングハンマーを選び、E / RT・R2で使用します。向いている方向へ水平速度12で放物線を描き、発射地点から射程9まで飛び、最初の敵1体に24ダメージを与えて消えます。ガード不能ですが、回避・ジャンプ・硬直による無敵は貫通しません。命中した生存敵は1.5秒気絶し、頭上にSTUNを表示します。気絶中は通常の被弾硬直と同じく追加ダメージを受けません。敵を追尾せず、奥行きが離れた敵には当たりません。発射後に振り向いても進行方向は維持します。

1回に1個消費し、使用後0.35秒は行動できません。空中・硬直中・所持数ゼロでは消費しません。無敵は付きません。画面のHAMMERSに所持数を表示します。調整値はBrawlerBalanceのHammer定数にまとめています。

## ガード・カウンター演出

正面の攻撃を盾で防いだ瞬間に、左右の向きを反映した盾の位置へ淡い黄色の火花を表示します。背後からの被弾には出しません。カウンターで実際に敵へダメージを与えると、大きな青白い十字エフェクトを追加します。空振りや硬直中の敵への無効な命中では出しません。

演出は実時間で更新し、ヒットストップ中にも広がって消えます。色の素材は共有し、表示時間・サイズ・光線数はBrawlerBalanceの演出定数で調整できます。

## 敵の足元の攻撃予告

敵が攻撃を準備すると足元に枠を表示し、予告の進行に合わせて黄色→橙色→赤へ変化します。左右の短い棒は攻撃方向を示します。近接・遠距離・重装・アンデッドの各敵に対応し、攻撃開始・被ダメージによる中断・死亡で非表示になります。既存の頭上の「!」も残しています。

近接型の枠は前方リーチ1.65・奥行き±0.8・背後0.25の攻撃範囲を示します。遠距離型は発射位置から弾の飛距離32・奥行き±0.45の射線を示します。射線は床へ投影した予告で、ジャンプ・ガード・無敵による命中の可否は既存の戦闘判定が決めます。戦闘側の予告時間から進行率を読み取り、演出側では別のタイマーを使いません。高さ・線の太さはBrawlerBalanceのWarningMarker定数、範囲は実際の攻撃・弾と共用する定数で調整できます。

## ダメージ数値表示

敵に実際に与えたダメージを頭上へ表示します。通常は白、カウンターは水色、大斬りは橙色の少し大きな文字です。硬直中の無効な命中や空振りでは表示しません。撃破時に残りHPを超える一撃を与えても、表示するのは実際に減ったHPです。

数値は敵とは独立したオブジェクトとして0.7秒表示し、ヒットストップ中も実時間で上昇・フェードアウトします。表示時間・上昇速度・高さ・文字サイズはBrawlerBalanceのDamageNumber定数で調整できます。

## 回復量の表示

回復魔法・ポーション・ウェーブ終了報酬でHPが増えると、プレイヤーの頭上へ緑色の「＋数値」を表示します。最大HPで切り止めた場合は実際に増えた分だけを表示し、満タン・回復不成立時には出しません。ダメージ表示と同じ仕組みで上昇・フェードし、ヒットストップ中にも実時間で進みます。

## アイテム取得通知

ポーション・スローイングハンマーを拾って所持数が増えたとき、頭上へ「ポーション＋1」「ハンマー＋1」を0.9秒表示します。所持上限・距離不足などで拾えなかった場合や二重取得の判定では通知しません。二種類の同時取得では表示の高さを分けます。取得通知もヒットストップ中に上昇して薄くなります。

ダメージ・回復・取得通知の描画はFloatingLabelを基底クラスとして共用しています。通知の高さ・時間・文字サイズはBrawlerBalanceのPickupNotice定数で調整できます。日本語表示にはOSのYu Gothic / Meiryoを使用します。

## 横並びの選択UI

画面下部の操作説明の上へ、HEAL / PROTECTION / POTION / HAMMERを横並びで表示します。各枠には残り回数・所持数と上限を表示し、選択中は黄色の枠と「>」で強調します。残りゼロの項目も選択できます。Q / View・Shareで選択、E / RT・R2で使用する操作は同じです。

四つの枠は画面幅に合わせてまとめて縮小します。表示サイズや余白はBrawlerBalanceのSelection定数で調整できます。描画はSelectionHudが担当し、所持数・入力処理は既存のクラスが管理します。

## 選択中の使用可否

選択UIの下にSELECTEDの状態を表示します。READYは使用可能、HP FULLはHP満タン、EMPTYは残りゼロ、PROTECTION ACTIVEは補助魔法の効果中、BUSYは攻撃・回避・硬直などの行動中、AIRBORNEは空中、DEFEATEDは死亡を示します。

表示と発動は同じ状態判定を使います。理由が重なる場合は死亡→空中→行動中→残り回数→個別の条件を優先します。状態照会だけでは回数を消費しません。

## 敵撃破時のフェード

撃破した敵は倒れた姿勢のまま、0.5秒で徐々に透明になって消えます。生存中のダウンでは薄くならず、従来どおり起き上がります。消滅の時間はゲーム内時間で進み、ヒットストップ中は停止します。

撃破時だけEnemyDefeatFadeを追加し、個体用のFade素材を複製して透明度を変えます。他の敵の共有素材には影響せず、複製素材は敵の破棄時に解放します。消滅時間はBrawlerBalance.EnemyRemovalSecondsで調整できます。

## ウェーブ開始・クリアの中央表示

敵が全滅して消えた後、中央に黄色のWAVE CLEARを一度表示します。次の敵の出現予告が始まると、水色のWAVE番号を表示します。各通知は1.2秒で消え、最後の0.3秒でフェードします。敗北時には通知を消します。

既存の次ウェーブ待ち2秒・出現予告1.5秒は維持します。出現待ちの敵がいる間はクリア通知を出しません。通知と進行はゲーム内時間で動き、ヒットストップ中は停止します。時間・文字サイズはBrawlerBalanceのWaveBanner定数で調整できます。

## 被ダメージ時のHPバー残像

プレイヤーが被弾すると、青い現在HPのバーは即座に縮み、減った部分を赤い残像として表示します。残像は0.25秒待ってから現在HPへ追いつきます。連続被弾では最後の被弾から待機をやり直し、回復すると古い残像を消します。HPゼロでも数値を表示します。

実際のHPには影響せず、HealthBarFeedbackが表示だけを管理します。ヒットストップ中は残像も停止します。待機時間・縮む速度・バーのサイズはBrawlerBalanceのHealthTrail / PlayerHealthBar定数で調整できます。

## 敵HPバーの残像

敵の頭上HPバーにも赤い残像を表示します。現在HPは橙色、攻撃予告中は黄色で示し、減った部分は0.25秒待ってから縮みます。敵ごとに最大HPに応じて計算し、他の敵の被弾には影響しません。回復で古い残像を消し、ヒットストップ中は停止します。撃破した敵の頭上バーは非表示になります。

残像の計算はプレイヤーと同じHealthBarFeedbackを共用します。幅・高さ・頭上位置はBrawlerBalanceのEnemyHealthBar定数で調整できます。

## 被弾方向の表示

プレイヤーのHPが実際に減ったとき、攻撃元の側へ赤い「<」「>」を0.6秒表示します。左からの攻撃は左側、右からの攻撃は右側です。ガード成功・回避無敵・硬直中の無効な命中では通知しません。向きを変えても記憶した被弾側は維持し、次の有効被弾で更新します。

通知は実時間で進み、最後の0.2秒で薄くなります。時間・位置・文字サイズはBrawlerBalanceのHitDirection定数で調整できます。

## プロテクションの終了予告

効果中は選択UIのPROTECTION枠へ残り秒数を表示します。残り3秒になると枠・背景が橙色に点滅し、「まもなく終了」と表示します。他の項目を選択中でも予告を表示し、効果終了後は通常表示へ戻ります。

予告は実際の効果時間から求め、ダメージ軽減や使用回数を変更しません。ヒットストップ中は効果時間と点滅が停止します。しきい値・点滅速度はBrawlerBalanceのProtectionWarning定数で調整できます。

## 低HPの警告

プレイヤーのHPが最大値の25％以下になると、HPバーの外枠が橙色に点滅し、横へLOW HPを表示します。実際のHPで判断し、回復して25％を超えるか、HPゼロになると解除します。現在HPのバー・赤い残像・数値はそのまま見えるようにしています。

点滅はゲーム内時間で進み、ヒットストップ中は停止します。しきい値・点滅速度・枠幅はBrawlerBalanceのLowHealthWarning定数で調整できます。

## ステージクリアとリザルト

5ウェーブを突破するとステージクリアです。最終ウェーブの敵が撃破後のフェードで消えた時点で、STAGE CLEAR・スコア・撃破数を中央の結果画面へ表示します。出現予告中や敵が残っている間はクリアしません。

クリア後は次のウェーブを出さず、移動・攻撃・被ダメージ・魔法やアイテム使用・拾得・得点更新を止めます。R / Startでシーンを読み直し、最初から再プレイできます。敗北時の既存のリスタート操作も利用できます。ウェーブ上限はBrawlerBalance.StageWaveCount、結果画面のサイズはResult定数で調整できます。

### 敗北リザルト

HP が 0 になると、到達ウェーブ・スコア・撃破数をその時点で確定して表示します。結果表示中は移動・攻撃・アイテム取得・敵の出現を停止します。R キー、またはパッドの Start ボタンで最初から再挑戦できます。

## コードの役割と調整方法

- `BeltBrawler`：ウェーブ進行、戦闘対象、得点・リザルト、命中演出の呼び出しを管理します。
- `BrawlerSceneFactory`：ステージ・キャラクターの仮モデル・共有マテリアルを生成します。生成した素材は管理役の終了時に `Dispose` で解放します。
- `BrawlerHud`：HUDを描画します。渡された状態を表示し、ゲーム進行やHPは変更しません。
- `Fighter`：移動、入力・AI、攻撃と被ダメージを担当します。攻撃の種類は `BrawlerDefines.AttackKind` の一つの値で保持し、切替・終了時の解除を共通化しています。種類と移動・空中・防御の状態は別に管理します。
- `BrawlerBalance`：得点、出現人数、HP、ドロップ間隔、命中演出などの調整値を集約します。魔法のHUD説明も同じ値を参照します。既存のコマンド技のCSV読み込みは維持しています。

技を追加する際は、種類の定義、開始処理、威力・命中タイミング・腕の演出の選択処理を確認してください。左右の向きや入力受付の順序を変更する際は、戦闘とパッド入力の検証も実行してください。追撃も通常攻撃と同様に、ゲーム終了後はダメージを受理しません。

検証コードのHP残像・技の切替・ステージクリアは項目ごとのメソッドへ分離しています。既存の入力・戦闘検証に加え、技の切替で以前の種別が残らないことと終了後の追撃拒否を確認します。

ハンマーの上向き速度・重力・回転・気絶時間はBrawlerBalanceのHammer定数で調整できます。発射位置から3.0上昇する弧を描き、命中後も地面に落ちるまで飛び続けます。曲線を小区間に分けて判定し、通常の敵には一投あたり1回、体格の大きい重装型には接触が続けば0.1秒以上の間隔で最大2回命中します。同じハンマーの2発目だけは気絶中もダメージを受理します。ナイフは従来どおり最初の命中または射程到達で消滅します。

## 職業ごとの投擲アイテム

ナイフとハンマーは別の所持品・設定・取得物として保持します。投擲物の基底クラス `PlayerThrownProjectile` は、発射方向の固定・時間による移動・射程・区間命中判定・二重命中防止・終了時の消滅を共用します。`ThrowingKnifeProjectile` は直進とダメージ、`ThrowingHammerProjectile` は放物線・回転・ダメージと気絶を担当します。

職業ごとの使用許可は `Fighter.CanUseAction` を上書きして指定します。クレリックは回復・補助魔法・ポーション・ハンマーを許可し、ナイフは選択・取得・使用しません。ナイフを許可したキャラは最大9本を独立して所持でき、使用時は1本消費、0.35秒の後隙があります。ナイフはガード不能で、回避・硬直中の無敵には従い、ハンマーの気絶を付けません。

現在のプレイヤーは引き続きクレリックです。ほかの職業の実装時に、使用許可と選択UI・固有行動を追加します。拾える投擲アイテムのドロップはハンマーを優先し、ハンマーを使用できずナイフを使用できるキャラにはナイフを落とします。

ハンマーの軌道は上向き速度6・重力18で、約0.333秒後に発射位置から1.0上昇します。命中判定は胴体中心から上下0.6の縦範囲を持ち、ナイフの中心点判定とは分けています。

近接攻撃は、同じ相手の被弾硬直中に同じ技を再ヒットさせません。途中に別の技を挟んでも、硬直が続く間は使用済みの技を再ヒットできません。通常コンボは段ごとに別の技として扱い、次段・未使用の別技はつながります。転倒・ハンマー気絶・回避中にはこの連携の例外を適用しません。

大斬り・ダッシュ必殺技・対空攻撃は確定クリティカルです。CSVの基礎威力に共通倍率1.5倍を適用（端数切り上げ）し、攻撃強化魔法はその後に適用します。敵はダメージ量に関係なく転倒し、ダメージ数字は黄色で表示します。既定の補正後威力は大斬り51・ダッシュ必殺技60・対空54です。倍率は `BrawlerBalance.CriticalDamageMultiplier` で調整できます。

## 共通処理の構成

`Fighter` は行動状態・移動・攻撃の進行を担当します。方向コマンドは `DirectionCommandBuffer`、ボタンの順番入力は `ButtonSequenceBuffer`、被弾硬直中の近接技の履歴は `MeleeHitHistory` に分離しています。履歴クラスは記録・照会・リセットを担当し、職業固有の能力は `ClericFighter` などの派生クラスに実装します。

職業の移動速度・通常リーチ・特殊技の武器リーチ倍率・使用許可は `PlayerClassCatalog` と `PlayerClassSettings` で管理します。`ClericFighter.ClassSettings` がクレリック設定を選択します。特殊技の基礎リーチは既存CSVを参照し、魔法の発動処理は派生クラスに残しています。

## 職業選択

右上のCLERIC／FIGHTERボタン、F1／F2、パッドView・Share＋十字キー左／右で、その職業として最初から開始します。通常のリスタートでは職業を維持します。ファイターは剣と盾を持ち、現在の共通攻撃・ガード・コマンド技を使用できます。魔法は使えず、拾ったナイフ・ハンマー・ポーションを6枠の所持欄から選択して使用します。初期所持は空で、歩行・走行・通常リーチは現在の共通値を使用します。

ドワーフは右上のDWARFボタン・F3・パッドView／Share＋上で選択できます。斧と盾を持ち、魔法を使わずファイターと同じアイテムを使用します。試作用の値は歩行4.5・走行7・通常リーチ2.2・特殊技リーチ倍率0.9です。小柄なモデルと通常攻撃の振り角で区別し、HP・威力・入力条件は共通です。調整値は `BrawlerBalance` のDwarf定数にまとめています。所持品操作は `ItemFighter` を継承して共用します。

シーフは右上のTHIEFボタン・F4・パッドView／Share＋下で選択できます。短剣を持ち、歩行6・走行9.5・通常リーチ1.8・特殊技リーチ倍率0.75の試作設定です。基本攻撃・ガード・所持品操作は共通で、魔法は使いません。調整値は `BrawlerBalance` のThief定数にまとめています。専用アクションは今後追加します。

シーフは空中でジャンプを押すと、着地までに一度だけ2段ジャンプできます。通常ジャンプの0.25秒以内の2回押しはバックステップを優先し、それ以降の空中入力を追加ジャンプとして扱います。空中攻撃中・被弾硬直中は出せず、被弾で残り回数を失います。追加の無敵はありません。着地後の次のジャンプで回数を戻します。追加上昇速度7は `ThiefAirJumpVelocity` で調整できます。入力の優先順位・速度は試作用の設定です。

シーフは空中で左右のステージ端から0.45以内にいるとき、ジャンプ入力で内側へ三角跳びします。着地まで1回で、2段ジャンプとは別枠です。入力はバックステップ→三角跳び→2段ジャンプの順に判定します。中央・奥行きの端・攻撃中・被弾硬直中では発動せず、被弾で残り回数を失います。上昇速度7・内側への移動速度8で、追加の無敵はありません。距離・速度・回数は `ThiefWallJump` 定数で調整できます。これらは試作設定です。

シーフは敵の背後で後ろ→前→攻撃を入力すると、近距離の1体へバックスタブを出します。前方向を先に入力して保持し、別の入力更新で攻撃を押します。試作設定は威力50・リーチ1.1・奥行き±0.5・攻撃0.45秒・後隙込み再使用待ち0.8秒です。ボス・転倒中の敵は対象外。命中時にも距離と背後を再判定し、掴み拘束はまだありません。通常コンボ・押し攻撃には派生せず、無敵は追加しません。調整値は `Backstab` 定数を参照します。

エルフの基本部分を追加しています。右上のELFボタン・F5・パッドView／Share＋Y・△で選択でき、剣・緑色の服・耳のパーツで区別します。試作設定は歩行5.5・走行8.5・通常リーチ2.3・特殊技リーチ倍率0.95です。近接攻撃とアイテム操作は共通処理を使います。調整値は `BrawlerBalance` のElf定数にまとめています。


エルフは初期所持のMAGIC MISSILE（3回）をE／RT・R2で使用できます。前方6以内・奥行き±0.65の最も近い敵1体へ24ダメージを与え、光の軌跡を表示します。後方の敵は対象外です。対象がいなくても1回消費し、使用後は0.6秒の硬直があります。空中・被弾・他の行動中は使用できず、無敵は付きません。個別上限9、0回でNOTHINGになる規則は共通です。詠唱0.4秒の完了時に効果を発動し、0.25秒の発動演出を経て0.6秒の硬直に移ります。回数は詠唱開始時に消費し、被弾すると詠唱を中断します（回数は戻りません）。詠唱中は黄色い構えとCASTING表示で示し、移動・攻撃・ガードはできません。所持欄を切り替えても詠唱中の魔法は変わりません。詠唱時間は試作の値です。値は `MagicMissile` 定数、共通処理は `AttackSpellFighter` で管理します。

エルフでは通算4体撃破ごとのスクロールがマジックミサイルを1回補充します。白い帯が目印で、ボス前の準備区間でも支給されます。未対応の職業・上限時は取得できません。

攻撃魔法の腕は、詠唱開始時に持ち上げて構え、完了直前に前へ振り出します。効果発動時には放つ姿勢となり、発動直後に短く維持した後、後隙の終了までに通常姿勢へ戻ります。左右はキャラクターの向きに合わせて反転し、被弾中断時は構えも解除します。角度・演出時間は `Spell` の腕演出定数で調整できます。

回復魔法と攻撃魔法は、共通の `SpellFighter` で「詠唱→発動演出→後隙」の3段階を管理します。マジックミサイルは詠唱0.4秒、発動演出0.25秒、後隙0.6秒の試作設定です。発動演出中は敵・ボスの移動、攻撃、硬直、アニメーションと既存の投擲物を止め、魔法の光は進行します。終了後に敵を再開し、術者は後隙へ移ります。魔法命中では通常攻撃のヒットストップを付けません。詠唱中と後隙中は敵が通常通り動きます。

回復・プロテクション・攻撃強化の発動時には専用の仮エフェクトを表示します。回復は緑の輪と上昇する十字、防御は金色の盾の輪郭、攻撃強化は橙色の上向きの光です。発動演出の進行率に合わせて拡大・上昇し、線と周囲の光が消えます。`SupportSpellEffect` は術者の発動状態に同期し、演出終了・中断・死亡・ゲーム終了で消去します。見た目の大きさ・線の幅・光の強さは `BrawlerBalance` の `SupportSpell` 定数で調整できます。

プロテクションの効果中は足元に金色の丸い輪、攻撃強化中は橙色の菱形のオーラを薄く表示します。併用時は両方を表示し、各効果の残り3秒で個別に点滅します。点滅は残り効果時間に同期するため、ヒットストップ中は停止します。効果終了・死亡・ゲーム終了では非表示になります。`SupportSpellAura` が表示を担当し、大きさ・透明度・点滅速度は `BrawlerBalance` の `Aura` 定数で調整できます。
